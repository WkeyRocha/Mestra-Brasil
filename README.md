# Site Mestra Brasil Educação

Site institucional responsivo criado a partir das informações da apresentação da Mestra Brasil, sem incorporar o PDF ao projeto.

## Visualização local

Abra `index.html` diretamente no navegador ou execute um servidor estático na pasta:

```powershell
python -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Estrutura

- `index.html` — conteúdo, semântica e componentes do site
- `styles.css` — identidade visual, responsividade e animações
- `script.js` — abertura, navegação, revelações, conteúdos interativos e contato

O formulário de contato abre o aplicativo de e-mail do visitante com a mensagem preenchida.
